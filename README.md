# Jorge Flock · SEI

Sitio estático de Jorge Flock para GitHub Pages. Las páginas de servicio mantienen las rutas del sitio original. Los recursos, las fuentes y el material audiovisual se sirven desde el repositorio.

Para revisar el sitio localmente, ejecutar `python -m http.server 8000` en la raíz y abrir `http://localhost:8000/`.

GitHub Pages publica desde la raíz de `main`. El contacto se gestiona mediante WhatsApp, teléfono o correo electrónico.

La demo de GitHub Pages incluye `noindex` en cada página para que la versión de prueba quede fuera de los resultados de búsqueda. Cuando esta versión pase al dominio final, quitá esa directiva, actualizá las URLs de las vistas previas y agregá las canónicas y el sitemap del dominio definitivo.
